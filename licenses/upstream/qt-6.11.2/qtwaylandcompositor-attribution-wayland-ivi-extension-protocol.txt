Source: https://doc.qt.io/qt-6.11/qtwaylandcompositor-attribution-wayland-ivi-extension-protocol.html
Qt release: 6.11.2

"Wayland IVI Extension" is forked from IVI Layer Management to define a common set of APIs by wayland style protocol and provide reference implementation which can be loaded on Weston.


Used in the Qt Wayland Compositor, and the Qt Wayland platform plugin.


The sources can be found in qtwayland/src/3rdparty/protocol/ivi/ivi-controller.xml and qtwayland/src/3rdparty/protocol/ivi/ivi-application.xml.
