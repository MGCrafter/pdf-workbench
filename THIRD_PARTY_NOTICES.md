## Complete texts

The unmodified Liberation Sans font, its original copyright statement, full
OFL license and source reference are included under `pdf_workbench/fonts`
in the application bundle and `src/pdf_workbench/fonts` in the source.

Public binary archives include a `licenses` directory generated by
`packaging/collect_notices.py`. Its `manifest.json` lists exact runtime/package
versions and SHA-256 hashes for every collected file. It contains original
license/notice files from installed distributions; full attributions for the
audited Qt 6.11.2 core, GUI, PDF and plugin modules; and CPython's complete
license appendix and OpenSSL license for the actual interpreter version.
Ubuntu builds also include installed native-package copyright files and a
versioned package inventory, deliberately covering a superset of the runtime.
The installed Python runtime's own license/notice files are retained unchanged
under `python/installed-runtime/`; these include Microsoft's Distributable Code
terms when supplied by the Windows interpreter distributor. Such terms apply
to those Microsoft DLLs, separately from the GPL application source.

The QtPdf texts cover all nine components listed by Qt: Abseil, FreeType,
PDFium, Chromium, fast_float, ICU, libjpeg-turbo, libpng and zlib. They include
PDFium's full `LICENSE` and `AUTHORS`, Chromium's `LICENSE`, and the original
2014 Foxit font-source copyright header with its governing BSD-style PDFium
license. This does not import a proprietary Foxit SDK license.

Additional nested PDFium notices are retained under `pdfium-third-party/`,
including Anti-Grain Geometry, bigint, FP16, Highway, Little CMS, OpenJPEG,
libtiff and Dragonbox. These are included conservatively as an upstream
superset: the QtPdf summary table alone does not enumerate every nested
source component. In particular, PDFium's own AGG metadata marks it as shipped.

The reviewed corpus is in `licenses/upstream/qt-6.11.2/`, with official source
URLs and hashes in `packaging/notices-lock.json`. PDFium notices are bound to
Qt's `v6.11.2` source and Chromium-submodule commit
`5170777d28bee1ce92cc693a0dbf2ad01492e5cf`. A generic Chromium license alone
does not substitute for these individual notices.

## Corresponding source and replacement

The matching GitHub release provides the application source/build scripts and
separate upstream source archives recorded in the manifests. The complete Qt
6.11.2 source archive includes its nested PDFium/Chromium sources. The source
job verifies upstream Qt/PyPI checksums and records every download's size and
SHA-256. Keep source archives available alongside the corresponding binaries;
successful notice collection alone does not establish that source assets were
uploaded. See [`docs/distribution.md`](docs/distribution.md).

The onedir build dynamically loads Qt libraries from ordinary extracted files.
Users may replace them with compatible modified builds and rebuild the app.
There is no signature gate or prohibition on reverse engineering modifications
to these libraries.

Historical `licenses/linux-build/` files document a local CachyOS development
build. They are not the notice manifest for public Ubuntu/Windows releases;
the historical bundles must not be published as having passed the new gate.
